# Process Map

Production Order created
        ↓
Material Requirement checked against stock
        ↓
Order scheduled to a Work Center (at a Plant)
        ↓
Production Run executed
        ↓ (if a stoppage occurs)
   Downtime Event logged → Production Run resumes
        ↓
Output goes through Quality Inspection
        ↓
   Pass → becomes a Finished Good, released
   Fail → returned for rework or scrapped
